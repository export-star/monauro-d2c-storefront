# MONAURO Compliance Language Guide

## Preferred Language

Use careful, support-oriented wording:

- designed to support recovery routines
- helps relieve everyday tension
- supports post-workout relaxation
- built for daily mobility and relaxation
- may help users feel more comfortable
- designed for focused relaxation

## Avoid

Do not use absolute or medical-treatment claims without verified legal and regulatory review:

- cure
- guaranteed recovery
- permanent pain relief
- clinically proven
- medical-grade
- treats injury
- treats disease
- improves circulation
- doctor recommended
- FDA approved
- HSA/FSA eligible

## Product Claims

Before publishing a claim, confirm:

- Product manual supports it
- Product data supports it
- Certification file exists if a certification is named
- Policy file exists if return, shipping, or warranty terms are named
- Permission exists if a person, clinic, reviewer, or KOL is named

## Disclaimer Direction

MONAURO product and educational content should not replace professional medical advice, diagnosis, or treatment. Users with medical conditions should consult a qualified professional before using heat, compression, EMS, or massage-related devices.
